# JM Batch Downloader

一款支持 Windows 和 Android 的 JM 批量下载工具。输入作品编号即可创建下载任务，支持 PDF 和图片 ZIP 两种输出格式。

## 功能

- **批量编号输入**：支持多个编号、换行输入和 JM 前缀。
- **连号快捷输入**：例如 `123450-123455`，自动展开为多个任务。
- **多种输出格式**：导出为 PDF 或图片 ZIP。
- **下载进度可视化**：查看任务状态、图片数量、下载速度和耗时。
- **可调下载线程**：根据网络情况调整并发数。
- **低速自动重试**：持续低速时自动重建连接，并限制重试次数。
- **明确的错误信息**：下载失败后可在任务详情中查看原因。
- **自定义保存目录**：支持选择输出路径。
- **可选文件整理方式**：仅用编号命名；单章节 ZIP 可平铺，多章节 ZIP 始终按章节分目录。
- **GitHub 更新检查**：新版本内置本仓库，后台检查最多等待 8 秒；无响应时跳过，不影响下载。可查看更新日志，支持应用内下载、进度与取消；验证更新清单签名和安装包 SHA-256 后确认安装。

- **安卓目录浏览**：首页和任务详情可打开对应保存目录，查看、打开或分享文件。

当前版本：**Windows 0.1.6 / Android 0.2.5**。前往 [下载页面](https://github.com/norskhelo/jmbatch/releases/tag/release-2026-10-13-3)，查看 [更新日志](CHANGELOG.md)。

## 下载与使用

在本仓库的 **Releases** 页面下载对应版本：

- **Windows**：下载 Windows ZIP，解压后运行程序。
- **Android**：下载 APK 并安装，支持 Android 8.0 及以上。

输入编号，选择输出格式和保存目录，然后开始下载。

输入示例：

    123456
    JM123458
    123460-123465

## 说明

本工具为独立第三方项目，与相关内容平台无隶属关系。下载速度和可用性受网络环境及上游服务影响；导出图片的格式与画质可能与官网直接下载的文件不同。

请仅下载你有权获取和保存的内容，并遵守所在地法律及相关平台条款。反馈问题时，请附上软件版本、系统版本和完整报错，避免公开账号、Cookie 等敏感信息。

## 应用内更新

在“软件更新”中检查并下载新版。Windows 点击“安装并重启”；安卓点击“安装新版”，由系统确认安装。旧版本需先手动升级至 Windows 0.1.6 / Android 0.2.5 一次。

只接受本项目发布密钥签署的更新包。安卓下载更新时请保持应用在前台，并在安装前暂停漫画下载。Windows 程序目录需可写，更新会保留备份。
