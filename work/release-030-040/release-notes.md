- 已下载漫画 / 收藏界面新增封面缩略图，默认取漫画第一页；多章节取第一章第一页，按章节和页码顺序读取。
- 同时支持图片文件夹、ZIP 和 PDF。封面按比例缩放，保留完整页面；ZIP 内的下载信息、隐藏文件不作为封面。
