# Windows 0.2.3 / Android 0.3.3 — 2026-10-15

## 多任务同时下载

- 下载队列支持同时下载多本漫画。设置中新增“同时下载任务数”，默认 2，可设为 1–4；设为 1 时按原来的顺序逐本下载。
- “每个任务图片线程数”独立控制单本的图片并发，仍为 1–16、默认 8。并行任务越多，总网络连接和内存占用越高，手机发热或遇到限流时可调低。
- 保存并行任务数后用于后续调度；提高上限时自动启动等待任务，降低上限时等待当前任务结束，不中断正在下载的漫画。新加入的任务也会自动补位。
- 各任务分别记录进度、速度、预计完成时间、缓存和自动重连次数。界面显示同时运行数量及总速度；Windows 选中运行中的任务可查看该任务的详细进度，Android 通知展示多个任务。
- 取消或失败的任务不会停止其他下载。暂停会停止全部任务并保留已验证缓存；Android 在旧请求完全退出后才释放任务名额，防止立即重试时重复写入缓存。关闭应用后重新打开，未完成任务保持暂停，点击开始继续。
- 其他网络参数继续用于新任务和手动重试；已有任务的保存目录和下载参数保持原快照。原有图片保存、PDF/ZIP 导出、收藏及更新签名验证继续保留。
