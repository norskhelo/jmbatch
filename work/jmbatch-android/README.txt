JM Batch 0.6.17 — Android 使用说明

本版双页交互：下载页与漫画库同时加载，点击后方露出的页面切换。淡化 0.33 秒、下滑 0.66 秒，切换期间锁定两页操作，结束后恢复。

设置入口仅保留齿轮图标；点击进入独立设置页，左右滑动进出并保留原页面状态。导出可开启“只保留编号”。

1. 在设置中选择保存目录，点击主页面右下角“＋”，输入编号或区间并选择 PDF、ZIP 或文件夹格式；点击“添加”后新任务自动开始。格式选择会保存，已有任务继续或重试时保持原格式。
2. 默认同时下载 2 本。在“下载设置”中将“同时下载任务数”设为 1–4；“每任务图片线程数”控制单本图片并发。
3. 调高任务数自动补位；调低时等待已运行任务结束。取消会删除该任务文件和记录，不影响其他任务；暂停会停止全部下载并保留缓存。
4. ZIP 只含图片，图片文件夹另含相册隐藏标记 .nomedia：单章节平铺，多章节先分章节文件夹再平铺图片；下载后可在任务详情或漫画库将 PDF、ZIP、文件夹互相导出，源文件保留。PDF 转图片按页渲染，可能损失画质，作为一个章节。导出和文件删除前请暂停下载并等待请求退出。
5. Windows 完整解压 ZIP 后运行 JMBatch.exe；Android 覆盖安装 APK，保留设置、队列和收藏。Android 卸载应用可能删除应用目录中的图片，请事先备份。

6. 漫画库 / 收藏列表默认显示第一页封面，多章节取第一章第一页。无法读取时显示占位图；恢复文件或授权后重新进入应用刷新。

7. 在任务列表或漫画库中打开漫画，即可使用内置阅读器。支持章节切换、本章/总页码、跳页、快捷收藏、书签列表及跳转；再次打开恢复上次页码和模式。滚动阅读与左右翻页可随时切换，轻点漫画隐藏或恢复工具栏，并有平滑过渡。Windows 使用滚轮、方向键或左右拖动，Android 使用上下滚动或左右滑动。Windows 按 Esc、Android 隐藏时按返回也可恢复工具栏。PDF 按一个章节显示。阅读记录绑定原文件路径/地址；移动文件或清除应用数据后不自动迁移。Android 外部 ZIP 首次打开需准备临时缓存，返回可取消，关闭后清理。

8. 更新日志随后台检查结果刷新；升级后保留本次升级起点和全部中间版本日志，重启或再次检查仍可查看。未来新版另列为“可用更新”。日志未取全时保留本版说明并明确提示，联网检查后补齐。

9. 下载列表会在首章第一页成功下载后自动显示封面，无需等待整本完成；暂停、继续和重启后可从缓存恢复。尚未就绪或无法读取时显示占位，完成后优先使用已保存的小尺寸封面，缺失时从 PDF、ZIP 或文件夹成品读取并缓存。

10. 在设置的软件更新区域手动检查新版本和查看更新日志。关闭启动自动检查后仍可使用；设置的有效修改自动保存。检查失败保留本地更新日志，可再次点击重试。下载和安装更新需要手动确认。

章节选择说明

多章节在获取列表后选择下载范围，支持多选、全选和稍后选择。设置中可默认下载全章节；单章直接下载。选中范围随任务保存，保留原章节编号，暂停和重试不增加未选择的章节。

Windows 0.3.32 / Android 0.6.15 — 备用 DNS 下载恢复与实时速度

发布日期：2026-10-22

Windows 0.3.30 → 0.3.32；Android 0.6.13 → 0.6.15（versionCode 614）。沿用原包名、APK 签名证书和更新公钥，可覆盖安装。

修复内容
• Android 为备用 IP 的连接、握手和响应头设置独立的单次等待上限；响应头超时后尝试其他地址，正文继续使用用户设置的读取超时。
• 图片正文超时、连接中断或内容不完整时记住失败 IP，暂时避让；成功完整读取后才更新优选地址。DNS 按 TTL 刷新时保留地址状态，包括旧请求稍后报告的失败；保留解析到的全部安全候选地址。
• 短期记住已确认的系统 DNS 全零结果，避免短 TTL 刷新反复经过已知失败的系统连接；不擅自延长 DNS TTL，代理与 HTTPS 证书校验规则保持有效。
• 慢速 CDN 探测不再长期占住探测机会，其他候选线路仍可被尝试。持续少量收包的图片连接按单请求读取耗时恢复，阈值按线程数分摊；图片处理、内存等待和写文件耗时不计入该慢速判断。
• Android 下载监控区分实际网络等待和本地处理，避免处理队列满或落盘较慢时重连整个任务。
• Windows 与 Android 统一显示实时有效速度：按最近约 1 秒内完成下载、图片处理并写入缓存的图片字节计算。网络和落盘不重复相加，不计缓存复用或失败重试，不再显示过去 10 秒的平滑速度；大图尚未完成时可能暂时为 0。

验证范围
• Android 10/15 共 20 项 HTTP/TLS 与下载监控框架检查通过，覆盖响应头超时取消、正文超时不被缩短、连接复用、证书校验及本地处理堵塞。
• Android 专项宿主回归覆盖 DNS 刷新、正文失败换址、CDN 探测、流水线、取消、重试与速度显示；Windows 32 项相关测试通过。
• 未连接 Android 真机；这些结果验证已确认的代码缺陷，不代表已实测用户移动网络上的吞吐或排除了运营商/CDN 路由差异。

新版界面：主页面 + 添加下载；漫画库长按批量操作；设置中配置合计下载限速（0 不限速）与阅读方式。
