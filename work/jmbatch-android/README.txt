JM Batch 0.5.2 — Android 使用说明

1. 选择保存目录和 PDF、ZIP 或文件夹格式，输入编号或区间并加入队列，点击开始。格式选择会保存，已有任务继续或重试时保持原格式。
2. 默认同时下载 2 本。在“下载设置”中将“同时下载任务数”设为 1–4；“每个任务图片线程数”控制单本图片并发。
3. 调高任务数自动补位；调低时等待已运行任务结束。取消单个任务不会影响其他任务；暂停会停止全部下载并保留缓存。
4. 文件夹和 ZIP 只含图片：单章节平铺，多章节先分章节文件夹再平铺图片；下载后可在任务详情或漫画库将 PDF、ZIP、文件夹互相导出，源文件保留。PDF 转图片按页渲染，可能损失画质，作为一个章节。导出和文件删除前请暂停下载并等待请求退出。
5. Windows 完整解压 ZIP 后运行 JMBatch.exe；Android 覆盖安装 APK，保留设置、队列和收藏。Android 卸载应用可能删除应用目录中的图片，请事先备份。

6. 漫画库 / 收藏列表默认显示第一页封面，多章节取第一章第一页。无法读取时显示占位图；恢复文件或授权后点击刷新。

7. 从任务或漫画库打开后直接在软件内阅读。支持章节切换、本章/总页码、跳页、快捷收藏、书签列表及跳转；再次打开恢复上次页码和模式。滚动阅读与左右翻页可随时切换，Windows 使用滚轮、方向键或页面两侧，Android 使用上下滚动、左右滑动或页面两侧。PDF 按一个章节显示。阅读记录绑定原文件路径/地址；移动文件或清除应用数据后不自动迁移。Android 外部 ZIP 首次打开需准备临时缓存，返回可取消，关闭后清理。

8. 更新公告随后台检查结果刷新；升级后保留本次升级起点和全部中间版本日志，重启或再次检查仍可查看。未来新版另列为“可用更新”。日志未取全时保留本版说明并明确提示，联网检查后补齐。

9. 下载列表会在首章第一页成功下载后自动显示封面，无需等待整本完成；暂停、继续和重启后可从缓存恢复。尚未就绪或无法读取时显示占位，完成后从 PDF、ZIP 或文件夹成品读取。

10. 点击主界面“检查更新 / 公告”立即联网检查，更新窗口与完整公告也可手动检查。关闭启动自动检查后仍可使用。检查采用已保存仓库；修改后先保存。检查失败保留离线公告，可再次点击重试。下载和安装新版需要手动确认。

章节选择说明

多章节在获取列表后选择下载范围，支持多选、全选和稍后选择。设置中可默认下载全章节；单章直接下载。选中范围随任务保存，保留原章节编号，暂停和重试不增加未选择的章节。

Android 0.5.2 — 2026-10-17

原生文件管理与保存目录跳转

• 修复荣耀 Play5 / Android 10 上“打开保存目录”误入云空间的问题：删除旧华为／荣耀包名兼容入口，并在自动打开、文档管理备用和其他应用选择中排除已确认的华为云空间包。
• 改用 Android 原生文件应用选择机制，启动系统实际声明的文件管理活动，不再打开猜测包名对应的应用首页。原生“文件”与文件选择器分别判断，保留可用系统默认项及启动失败回退。
• 文件管理器明确支持目录查看时，以目录地址请求直接打开保存目录；同时支持默认保存目录、自选目录及软件内当前子目录。默认目录使用只读文档目录树地址，供接收方读取子目录和图片。
• 不支持目录跳转时打开原生文件应用首页，并显示可复制的保存位置；不会把打开首页显示为已定位。仍可手动使用文档管理或软件内查看。
• 不移动文件、不更改保存设置、不新增存储权限。目录跳转取决于手机文件应用支持；系统应用可能忽略地址，原生界面也由设备决定。
