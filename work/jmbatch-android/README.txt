连接错误自动切换线路（双端）

• 漫画接口和图片下载发生连接失败时，优先轮换到其他线路，不再先在同一条线路耗尽重试。
• 针对连接目标显示 `[::]` / `0.0.0.0`、DNS 解析失败、连接拒绝或重置、网络不可达、HTTPS 握手或证书错误，在本次请求中跳过失败线路，尝试其他线路。
• 动态 API 线路与内置备用线路合并并去重，动态列表不再覆盖掉内置备用。成功的 API 线路在当前客户端中优先使用；全部失败后，下次初始化重新获取线路列表。安卓线路缓存最长十分钟。

• 接口切线时显示当前尝试的域名和请求次数；全部失败后，在任务详情汇总失败阶段、各域名、尝试次数及错误类别。

明确报错与处理边界

• 区分异常目标地址、DNS 失败、连接失败、超时、HTTPS/证书错误、服务器响应异常，并提示检查应用联网权限、网络、DNS、代理和过滤设置。
• 异常地址只表示需要排查，不把它直接判定为手机型号缺陷、DNS 污染或某个软件拦截。
• HTTP 401 / 403 / 404 / 429 仍按权限、资源不存在或限流报错，不通过换线反复请求；本地存储错误和取消操作不当作线路故障。
• 保留 HTTPS 证书校验和系统 DNS/代理设置；不硬编码服务器 IP，不强制关闭 IPv6，也不绕过系统联网限制。若全部线路都不可达，软件不能保证恢复连接。
• 线路诊断不包含 Cookie、令牌、完整请求 URL 或漫画请求参数。

默认请求超时 25 秒，单次请求重试 2 次。
图片下载阶段有 30 秒起始宽限，再判断 90 秒观察窗口是否低于 30 KB/s。
连接/下载阶段连续 180 秒无进度时也会触发恢复。
恢复会断开旧请求并等待旧线程结束，再创建新的下载会话；保留已验证图片。
每本最多自动重置 3 次，超过后显示明确错误并继续下一任务。
阈值、窗口、停滞超时、重置上限均可调整；阈值 0 表示只检测无进度。
校验、PDF/ZIP 导出和保存阶段不受慢速重置影响，可手动暂停。
暂停/取消可能需要等待当前解码或网络调用退出；不同时启动第二套旧任务。
严重网络阻塞导致旧线程不能及时退出时，停止该任务并报错，防止叠加写入。

## 受影响设备如何升级

若旧版已经出现 SigningInfo 空指针错误，需要先手动下载本版 APK 并覆盖安装一次，因为旧版的校验逻辑无法由新安装包远程修复。
安装前暂停下载，不要卸载旧版或清除应用数据。其他设备可继续从应用内更新。
