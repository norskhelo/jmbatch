JM Batch 0.3.17 — Windows 使用说明

1. 选择保存目录和 PDF、ZIP 或文件夹格式，输入编号或区间并加入队列，点击“开始下载”。格式选择会保存，已有任务继续或重试时保持原格式。
2. 默认同时下载 2 本。在“下载设置”中将“同时下载任务数”设为 1–4；“每任务图片线程数”控制单本图片并发。
3. 调高任务数自动补位；调低时等待已运行任务结束。取消会删除该任务文件和记录，不影响其他任务；暂停会停止全部下载并保留缓存。
4. 文件夹和 ZIP 只含图片：单章节平铺，多章节先分章节文件夹再平铺图片；下载后可在任务详情或漫画库将 PDF、ZIP、文件夹互相导出，源文件保留。PDF 转图片按页渲染，可能损失画质，作为一个章节。导出和文件删除前请暂停下载并等待请求退出。
5. Windows 完整解压 ZIP 后运行 JMBatch.exe；Android 覆盖安装 APK，保留设置、队列和收藏。Android 卸载应用可能删除应用目录中的图片，请事先备份。

6. 漫画库 / 收藏列表默认显示第一页封面，多章节取第一章第一页。无法读取时显示占位图；恢复文件或授权后点击刷新。

7. 在任务列表或漫画库中打开漫画，即可使用内置阅读器。支持章节切换、本章/总页码、跳页、快捷收藏、书签列表及跳转；再次打开恢复上次页码和模式。滚动阅读与左右翻页可随时切换，轻点漫画隐藏或恢复工具栏，并有平滑过渡。Windows 使用滚轮、方向键或左右拖动，Android 使用上下滚动或左右滑动。Windows 按 Esc、Android 隐藏时按返回也可恢复工具栏。PDF 按一个章节显示。阅读记录绑定原文件路径/地址；移动文件或清除应用数据后不自动迁移。Android 外部 ZIP 首次打开需准备临时缓存，返回可取消，关闭后清理。

8. 更新日志随后台检查结果刷新；升级后保留本次升级起点和全部中间版本日志，重启或再次检查仍可查看。未来新版另列为“可用更新”。日志未取全时保留本版说明并明确提示，联网检查后补齐。

9. 下载列表会在首章第一页成功下载后自动显示封面，无需等待整本完成；暂停、继续和重启后可从缓存恢复。尚未就绪或无法读取时显示占位，完成后从 PDF、ZIP 或文件夹成品读取。

10. 点击主界面“软件更新”立即联网检查，更新窗口与完整更新日志也可手动检查。关闭启动自动检查后仍可使用。检查采用已保存仓库；修改后先保存。检查失败保留本地更新日志，可再次点击重试。下载和安装更新需要手动确认。

章节选择说明

多章节在获取列表后选择下载范围，支持多选、全选和稍后选择。设置中可默认下载全章节；单章直接下载。选中范围随任务保存，保留原章节编号，暂停和重试不增加未选择的章节。

Windows 0.3.17 / Android 0.5.13 — 漫画库批量导出

漫画库

• 批量处理支持一次导出多本漫画。长按进入批量模式，勾选多本后点击“导出漫画”，统一选择导出格式和保存目录。
• 支持混选图片文件夹、ZIP 和 PDF，逐本导出为独立文件，不合并不同漫画；保留纯编号命名和按章节分别导出 PDF 的选项。
• 导出时显示当前漫画和总进度，结束后汇总成功、失败、未处理的漫画数量及已保存项目数，并将已导出的结果加入漫画库。
• 单本失败后继续处理其余漫画；同名文件拒绝覆盖并列出失败原因。停止导出会清理当前漫画未完成的输出，保留此前完成的结果和全部源漫画。
• Android 停止导出后保持进度提示，等待清理与汇总完成；完成后刷新漫画库。导出前继续检查下载与其他文件操作状态。
